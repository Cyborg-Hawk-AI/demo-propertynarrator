## Product specification

**Target customer:** Real estate investors evaluating new acquisitions or reviewing existing portfolio performance

### Core MVP features
- Input property address + purchase price + rent + expenses; AI fetches comparable rents via public data
- Generates plain-English verdict: 'This property cash flows $340/mo but your cap rate is below market — here's why'
- Side-by-side portfolio comparison: rank all properties by cash-on-cash return
- What-if scenario engine: 'What if rent increases 10%?' or 'What if vacancy hits 15%?'
- Shareable PDF deal memo for partners or lenders, auto-generated by AI

**Pricing:** Per-report credits plus monthly subscription at $9 per deal report (pay-as-you-go) or $39/mo unlimited reports

**Go-to-market:** BiggerPockets community, r/realestateinvesting, real estate investor Facebook groups, SEO targeting 'rental property cash flow calculator'

**Competitive landscape:** DealCheck exists for deal analysis but produces raw numbers with no narrative; no tool generates plain-English investment memos with AI narrative for small investors

**Agentic automation plan:** User submits property data; agent auto-fetches public rent comps, runs financial model, generates narrative via LLM, renders PDF — fully automated from input to downloadable report in under 60 seconds

**MVP estimate:** Next.js + Supabase + self-hosted LLaMA for narrative generation + Puppeteer for PDF export; 2–3 weeks to MVP with manual comp data entry before API integrations
